# Default keymap

The base layer follows the printed layout. Hyper holds media/navigation
controls; Hyper + R enters the bootloader. Circle taps F24 and holds the
lighting layer; Circle + X also enters the bootloader.

Circle + F1/F2 controls brightness, F3/F4 hue, F5/F6 saturation, F7/F8
the effect, F9 the lighting toggle, and F10/F11 the gradient/modifier shift.
Brightness, hue, saturation and shift repeat while held. Lighting changes
are saved three seconds after the last adjustment or before a reset.
