# MAGICFORCE V17

![V17](https://i.meee.com.tw/oypYXeh.jpg)

A 17-key numpad powered by the WestBerry WB32FQ95 microcontroller.

* Keyboard Maintainer: [GSKY](https://github.com/gskygithub)
* Hardware Supported: MAGICFORCE V17 PCB (WB32FQ95)
* Hardware Availability: [MAGICFORCE](http://www.magicforce.cn/)

Make example for this keyboard (after setting up your build environment):

    make magicforce/v17:default

Flashing example for this keyboard:

    make magicforce/v17:default:flash

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information. Brand new to QMK? Start with our [Complete Newbs Guide](https://docs.qmk.fm/#/newbs).

Enter the bootloader in 3 ways:

* Hold the Reset switch mounted after the USB cable is connected
* Hold the Num Lock key while connecting the USB cable (also erases persistent settings)
* Hold Num Lock and press `0` will reset the board to bootloader mode
