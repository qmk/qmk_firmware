# Sweep Cat v2

![Sweep Cat v2](https://raw.githubusercontent.com/smallwat3r/sweep-cat/main/images/v2.png)

The current Sweep Cat, adding 8° of splay to the pinky column and 3° to the ring finger column.
Electrically identical to v1.

See the [Sweep Cat readme](../readme.md) for build and flashing instructions.

    make smallwat3r/sweep_cat/v2:default
