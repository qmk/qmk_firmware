# raphaelsmadja keymap

Personal keymap for the Corne V4.1 (`keyboards/crkbd/rev4_1/standard`). See the
repo's `CLAUDE.md` for the key naming convention (querty/pinky/thumb) and layer
overview.

The diagram below is generated from `keymap.c` with
[keymap-drawer](https://github.com/caksoylar/keymap-drawer) and kept up to
date by the "Draw keymap" GitHub Action (`.github/workflows/draw-keymap.yml`),
which runs automatically on every push to `raph` that touches `keymap.c`, and
can also be run manually from the Actions tab.
